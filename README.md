# TRIBUILD — demo website (GitHub Pages)

Clickable demo of the TRIBUILD store for the client. Not a live store: no payments, example products and prices.

## Publish on GitHub Pages (free, no domain needed)
1. github.com → New repository → name `tribuild-demo` → Public → Create.
2. "uploading an existing file" → drag in `index.html`, `README.md` and the whole `images` folder → Commit changes.
3. Settings → Pages → Source: Deploy from a branch → Branch: `main`, folder `/ (root)` → Save.
4. After 1–2 minutes the site is at `https://YOUR-USERNAME.github.io/tribuild-demo/`.
Free GitHub Pages needs a public repository. The page has `noindex` so search engines skip it.

## Video (optional)
| File | Where |
|---|---|
| hero.mp4 | Home hero background |
| rain.mp4 | Rainwear block background |
- 10–15 seconds, no sound, loops cleanly, MP4 (H.264), 1920×1080 or 1280×720, ideally under 3–5 MB.
- Plays only on screens 750 px and wider. Phones, data-saver and "reduce motion" users see the photo instead.
- A "Pause video" button appears automatically (accessibility requirement).
- Free sources: Pexels Videos, Pixabay Videos (check each licence). AI video (e.g. Veo) is fine for the demo; label as illustration.
Already included: logo-mark.svg (redrawn mark), texture.jpg, coming-soon.jpg, badge.jpg.
